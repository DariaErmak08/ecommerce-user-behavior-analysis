# 🛒 E-commerce User Behavior Analysis

## ✅ Project Summary

This project explores user behavior and purchasing trends in an online retail store using exploratory data analysis (EDA). The aim is to uncover actionable insights from raw event data — from views to purchases — and provide recommendations to improve conversions and user experience.

---

## 🔍 Goal

- Analyze millions of user events (views, cart additions, purchases)
- Identify product and category performance
- Detect user activity trends across time
- Recommend data-driven strategies to increase conversion and revenue

---

## 📊 Key Insights

- **Very low conversion rate**: over 40M product views vs. ~742K purchases
- **Purchases peak during 2–9 AM**, suggesting timezone influence
- **Electronics.smartphone** is the top category in both views and purchases
- **Top-selling items ≠ Top revenue generators**: pricing strategy matters
- **Weekday activity peaks mid-week** (Tue–Thu)

---

## 💡 Recommendations

- Improve visuals and pricing of highly viewed but underperforming products
- Run marketing campaigns during active hours and days
- Promote high-margin products more aggressively
- Target top customers with loyalty incentives and rewards
